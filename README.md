# Peptide Store

A static storefront for consumer research peptides (BPC-157, TB-500 and the rest of the starter range), selling mostly in Europe. No build step — plain HTML, CSS and JavaScript that works as-is on GitHub Pages and Vercel.

## What it is

- **Working name:** "Peptide Store" — a neutral placeholder. Rename it in `data/products.json` (`store` field), the page titles, and the header logo when the client picks a real name.
- **Catalog:** 100 listings in `data/products.json`, in six categories (Healing 23, Growth / Secretagogues 32, Cognitive 35, Tanning 3, Cellular 4, Bundles 3). Each listing is one distinct purchasable variant (compound + size/form) with one verified price. Every name, size and price was read from a live store page on 2026-11-06. Prices are in USD for now; the client will set EUR pricing later. The site says so on the shop, checkout and footer.
- **Where the 100 come from:** LabFirst Peptides cost-per-mg list (87 listings), Sports Technology Labs (3: Tesamorelin 2 mg, MOTS-c 5 mg, Glow Bundle), Ouralus (4: BPC-157 20 mg, NA-Semax 30 mg, DSIP 15 mg, FOXO4-DRI 5 mg), SwissChems (6: BPC-157 capsules, TB-500 capsules, KPV capsules, Glutathione 600 mg, Healing Research Bundle, Longevity Research Bundle). Where two stores verified the same variant (e.g. BPC-157 5 mg), one price is listed (LabFirst's) and the duplicate is not listed twice — the other verified price is recorded in the build notes in `data/products.json` only as the source of that listing. Each listing in `data/products.json` carries a `source` field (store + live page URL) so any price can be traced back.
- **Excluded on purpose:** all GLP-1s (semaglutide, tirzepatide, retatrutide, dulaglutide, CagriSema, cagrilintide, mazdutide, survodutide); non-peptides (5-AMINO-1MQ, AICAR, MK-677, clomiphene, T3/T4, etc.); blends of unknown composition (KLOW, GLOW, ADMAX); rPeptide lab reagents (Beta-Amyloid, Tau, Synuclein); any variant whose price was only shown as a range (e.g. SwissChems BPC-157 with Arginine Salt $39.99–$599.50, HCG, Ipamorelin 2 mg ranges). Nothing was invented to reach 100 — the count is exactly the verified distinct variants found.
- **Guest checkout only:** there is no account anywhere. Customers add to cart (saved in their browser's local storage), fill in name, email and a European delivery address, and place an order request. No login, no password, ever.
- **Order requests, not payments:** checkout does not take money. On submit the customer gets an order reference (`PEP-2026-XXXXXX`) and is told the store will email payment details (bank transfer / crypto) and confirm shipping. No PayPal anywhere. Real payment instructions must be added by the client — see "Still needed" below.
- **Legal framing:** every product page and the footer carry the research-use-only notice. Product descriptions describe identity only (what it is, size, form). No health or benefit claims anywhere.

## Product photos

Product images are clean inline SVG vial illustrations generated by `js/shop.js` (one per product, same style, coloured by category). No other store's photos are used, copied or hotlinked. **Swap in real product photos once the client supplies them** — replace the `vialSVG()` call in the product card / product detail with an `<img>` and put the files in an `images/` folder.

## Files

- `index.html` — homepage: hero, categories, featured products, how ordering works
- `shop.html` — full catalog with search and category filter
- `product.html` — product detail with size selector, per-mg price, add to cart
- `cart.html` — cart with quantities and remove
- `checkout.html` — guest checkout form (European country list)
- `confirmation.html` — order confirmation with reference and summary
- `terms.html`, `privacy.html` — terms of sale and privacy notice
- `css/style.css` — all styles
- `js/shop.js` — catalog data, rendering, search/filter, product page, SVG vials
- `js/cart.js` — cart (localStorage), checkout, order reference, confirmation
- `data/products.json` — the 24 products, categories, prices

## Deploy

- GitHub Pages: enable Pages on the `main` branch (root). The site is static, so it serves as-is.
- Vercel: import the repo, no build command, no environment variables.

## Still needed from the client

1. **Store name** (and domain) — to replace the "Peptide Store" working name.
2. **EUR pricing** — prices are USD now; the client sets euro prices.
3. **Payment details** — bank transfer details and/or crypto wallet addresses, so the store can email them after an order request. Also whether cards are accepted at all.
4. **Shipping rates and delivery times** for Europe — the site currently says shipping is confirmed by email.
5. **Store contact email** — for the terms/privacy pages and order emails.
6. **Real product photos** — to replace the SVG stand-ins.
7. **Order handling** — v1 stores orders in the customer's browser only (order reference shown on screen). The store needs an inbox or order system to actually receive orders; until then, orders must be confirmed by the customer emailing the store, or a backend added later.

## What is NOT in this store

- No GLP-1s (semaglutide, tirzepatide), no non-peptide longevity items, no rPeptide-style lab reagents (Beta-Amyloid, Tau, Synuclein). Those were excluded on purpose.
- No accounts, no logins, no passwords, no payment processing.
